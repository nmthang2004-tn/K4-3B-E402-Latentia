🏷️ Chuyển tiếp câu hỏi cho Trợ giảng (@TA)

Hệ thống AI không tìm thấy căn cứ văn bản chính thức cho câu hỏi này. Để đảm bảo không đưa ra thông tin sai lệch, câu hỏi của bạn sẽ được chuyển tiếp kèm ngữ cảnh cho Trợ giảng:

NỘI DUNG CÂU HỎI:

📤 Hướng dẫn gửi Prototype cho người khác test

✅ HOÀN TOÀN GỬI ĐƯỢC! Bản prototype này được đóng gói dạng Single-File Web App độc lập. Người nhận không cần cài Node.js, không cần chạy web server, mở được trên mọi máy tính và điện thoại.
Cách 1: Gửi trực tiếp file `index.html` (Nhanh nhất - 5 giây)

Gửi file codebase/prototype/index.html qua Zalo, Discord, Google Drive hoặc Email. Người nhận chỉ cần nhấp đúp chuột là file sẽ mở trực tiếp trên Chrome, Edge, Safari hoặc Cốc Cốc.

Cách 2: Bật GitHub Pages từ Repository (Có link HTTPS online)

Vào GitHub repo nhóm > Settings > Pages > chọn branch main và thư mục chứa code để tạo đường link online miễn phí gửi cho giảng viên / TA / bạn bè test trên điện thoại.

Cách 3: Thả lên Vercel / Netlify (1 click)

Kéo thả thư mục codebase/prototype vào trang drop.vercel.app hoặc Netlify Drop để nhận ngay đường link công khai trong 10 giây.
